Privacy policy

videoauto uploader is a personal tool run on its owner's own computer.

  • It requests only the YouTube upload permission (youtube.upload) for the owner's Google account.
  • The access token is stored only on the owner's computer, in a local file. It is never sent to any server run by the author, and never shared with third parties.
  • The tool does not collect, store or sell any data about other people.
  • Videos are uploaded only to the owner's own YouTube channel.
